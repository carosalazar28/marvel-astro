# UC-03: Filtrar y ordenar el calendario

**Actor:** persona usuaria local.

**Precondición:** el calendario contiene ítems con estado, tipo y fase.

**Flujo principal:** elige filtros de visto/pendiente, tipo o fase, y un criterio de orden; la lista y el recuento reflejan las selecciones.

**Resultado:** encuentra rápidamente el subconjunto deseado sin alterar los datos originales ni su progreso.

**Casos límite:** combinación sin resultados, catálogo vacío, filtro reiniciado y valores de fase/tipo no válidos. Un resultado vacío se explica con un estado visible y accesible.
